# JiraViz CLI Usage Guide for Linux

This guide is for people who have never used a command-line tool before. It assumes you are using a Linux VM and JiraViz is already available at this exact path:

```text
/opt/jiraviz/jiraviz
```

It also assumes your Jira CSV file is in a local working directory on the VM:

```text
~/jiraviz-work
```

JiraViz reads a Jira CSV export and creates an SVG image report. You can download the SVG from the VM, open it in a browser, or view it with any tool that supports SVG images.

## What JiraViz Creates

JiraViz creates a Scrum portfolio report like this:

![Pine Ridge Scrum portfolio report generated by JiraViz](images/program-portfolio-report.png)

The report shows release timing, release percent complete, and the most important epics over the next six months.

For Scrum teams, run with `-mode points` to rank Important Epics by story points. For Kanban teams, run with `-mode issues` to keep the same report layout and rank Important Epics by planned issue count.

Kanban version of the same project:

![Pine Ridge Kanban portfolio report generated by JiraViz](images/kanban-top-epics.png)

Next six months of epics example:

![Next six months of epics generated by JiraViz](images/all-epics-six-month-gantt.png)

This example is generated from `house-renovation-jira.csv` with `-view epics-six-month`.

## Before You Start

You need:

- Access to the Linux VM
- JiraViz available at `/opt/jiraviz/jiraviz`
- A Jira CSV export copied into a local directory on the VM
- A terminal session connected to the VM

This guide uses this example local directory:

```text
~/jiraviz-work
```

This guide uses this example CSV file:

```text
~/jiraviz-work/construction-company-multi-project-jira.csv
```

If your CSV has a different name, replace the example file name with your real file name.

## Step 1: Open a Terminal Session

Connect to the Linux VM using the method your team provides. That might be SSH, a cloud console, a remote desktop terminal, or an integrated terminal in your development environment.

When the terminal opens, you should see a prompt where you can type commands.

## Step 2: Go to Your Local Working Directory

Run:

```bash
cd ~/jiraviz-work
```

Check that your CSV is there:

```bash
ls
```

You should see your Jira CSV file in the output.

## Step 3: Check That JiraViz Runs

Run:

```bash
/opt/jiraviz/jiraviz -version
```

You should see version information similar to:

```text
JiraViz 0.1.0 commit=... built=...
```

If Linux says `No such file or directory`, confirm that JiraViz is installed at:

```text
/opt/jiraviz/jiraviz
```

## Step 4: List Projects in Your CSV

Before rendering a report, ask JiraViz which projects it can see in the CSV:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -list-projects
```

Example output:

```text
Projects:
- MAP (22 issues)
- OAK (22 issues)
- PINE (31 issues)
```

This means the CSV has three project choices: `MAP`, `OAK`, and `PINE`.

## Step 5: Create Your First Report

Create a report for the Pine Ridge project:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -project PINE -out pine-report.svg
```

If it works, JiraViz prints:

```text
wrote pine-report.svg
```

You now have a new image file named `pine-report.svg` in the same local directory as your CSV.

## Step 6: Confirm the Report Was Created

Run:

```bash
ls
```

You should see:

```text
pine-report.svg
```

To see more file details, run:

```bash
ls -lh pine-report.svg
```

## Step 7: View or Download the Report

The output file is an SVG image. How you open it depends on how you access the VM.

If your VM has a desktop or browser, you may be able to run:

```bash
xdg-open pine-report.svg
```

If you connect with SSH, download `pine-report.svg` from `~/jiraviz-work` to your local computer, then open it in Edge, Chrome, Firefox, Safari, or another SVG viewer.

## Step 8: Create Reports for Other Projects

Use the same command and change the `-project` value.

Oak Street:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -project OAK -out oak-report.svg
```

Maple Avenue:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -project MAP -out maple-report.svg
```

## The Command Pattern

Most JiraViz commands follow this shape:

```bash
/opt/jiraviz/jiraviz -input YOUR_CSV_FILE.csv -project PROJECT_NAME -out OUTPUT_FILE.svg
```

The pieces mean:

- `/opt/jiraviz/jiraviz` starts JiraViz
- `-input YOUR_CSV_FILE.csv` tells JiraViz which CSV to read
- `-project PROJECT_NAME` chooses one project from the CSV
- `-out OUTPUT_FILE.svg` names the image file JiraViz will create

Example:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -project OAK -out oak-report.svg
```

## Flags

Flags are command options that start with a dash.

| Flag | Required? | What it does | Example |
| --- | --- | --- | --- |
| `-input` | Yes | Path to the Jira CSV file | `-input jira-export.csv` |
| `-project` | Usually | Chooses one project from the CSV | `-project PINE` |
| `-out` | No | Names the SVG report file | `-out pine-report.svg` |
| `-view` | No | Chooses the report view | `-view epics-six-month` |
| `-list-projects` | No | Lists projects in the CSV and exits | `-list-projects` |
| `-mode` | No | Chooses how Important Epics are ranked | `-mode issues` |
| `-as-of` | No | Sets the report date for repeatable output | `-as-of 2026-05-16` |
| `-sample` | No | Writes a small sample CSV to the input path before rendering | `-sample` |
| `-version` | No | Prints the JiraViz version | `-version` |

## Choosing Important Epics

The Important Epics block shows the largest epics over the next six months.

By default, JiraViz uses story points when the CSV has story points. If story points are not available, JiraViz uses the number of planned issues.

Scrum ranking by story points:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -project PINE -mode points -out pine-scrum-report.svg
```

Kanban ranking by planned issue count:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -project PINE -mode issues -out pine-kanban-report.svg
```

Default behavior uses story points when story points are available, otherwise planned issue count:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -project PINE -out pine-report.svg
```

## Creating the Six-Month Epic Schedule

Use `-view epics-six-month` when you want the standalone Gantt-style view of all epics that intersect the next six months:

```bash
/opt/jiraviz/jiraviz -input house-renovation-jira.csv -project REN -view epics-six-month -out house-renovation-epics-six-month.svg -as-of 2026-05-01
```

## Making the Same Image Every Time

By default, JiraViz uses today as the report date. That means the six-month window changes as time passes.

For demos, screenshots, tests, or documentation, use `-as-of`:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -project PINE -out pine-report.svg -as-of 2026-05-16
```

This makes the report behave as if it were generated on May 16, 2026.

## Using Your Own Jira CSV Export

Copy your Jira CSV export into the local VM directory:

```text
~/jiraviz-work
```

Then go to that directory:

```bash
cd ~/jiraviz-work
```

List the projects:

```bash
/opt/jiraviz/jiraviz -input jira-export.csv -list-projects
```

Then choose a project and render the report:

```bash
/opt/jiraviz/jiraviz -input jira-export.csv -project YOURPROJECT -out your-project-report.svg
```

Replace:

- `jira-export.csv` with the name of your Jira CSV file
- `YOURPROJECT` with the project name or key shown by `-list-projects`
- `your-project-report.svg` with the report file name you want

## Paths With Spaces

If a file path has spaces, put quotation marks around it.

Example:

```bash
/opt/jiraviz/jiraviz -input "jira export.csv" -project PINE -out "pine report.svg"
```

## Expected CSV Fields

JiraViz accepts common Jira CSV column names. The sample file uses:

```text
Project
Key
Summary
Issue Type
Status
Assignee
Fix Version/s
Epic Link
Parent
Start Date
Due Date
Story Points
Planned
Depends On
Blocks
```

The most important fields are:

- `Project`: lets you choose a project with `-project`
- `Key`: Jira issue key, such as `PINE-100`
- `Issue Type`: Epic, Story, Task, etc.
- `Status`: used to calculate percent complete
- `Fix Version/s`: used for release rows
- `Epic Link` or `Parent`: connects stories/tasks to epics
- `Start Date` and `Due Date`: used for timeline bars
- `Story Points`: used to rank Important Epics
- `Planned`: marks whether an issue should count in the report

If there is no `Project` column, JiraViz can infer the project from the issue key prefix. For example, `PINE-100` becomes project `PINE`.

## Common Problems

### Linux says "No such file or directory"

Check the path you typed. The JiraViz binary should be here:

```text
/opt/jiraviz/jiraviz
```

Also check that the CSV file name after `-input` is correct and that you are in the directory containing the CSV.

### Linux says "Permission denied"

The binary may not have execute permission. Ask the VM administrator to make `/opt/jiraviz/jiraviz` executable.

### I see "multiple projects found"

The CSV has more than one project. List the projects first:

```bash
/opt/jiraviz/jiraviz -input construction-company-multi-project-jira.csv -list-projects
```

Then run the report command again with `-project`.

### I do not know my project name

Use:

```bash
/opt/jiraviz/jiraviz -input jira-export.csv -list-projects
```

### My report has missing dates

Check that your CSV has `Start Date` and `Due Date` columns. JiraViz can still render without them, but the timeline will be less useful.

### My Important Epics look wrong

Check whether your CSV has story points. If you do not use story points, rank by issue count:

```bash
/opt/jiraviz/jiraviz -input jira-export.csv -project YOURPROJECT -mode issues -out report.svg
```

### I typed the command and nothing opened

JiraViz creates the SVG file, but it does not automatically open it. After you see `wrote filename.svg`, download or open the SVG yourself.
